ABI Changelog

This page tracks ABI evolution for strat9-abi.

Versioning policy

  • Major (ABI_VERSION_MAJOR) changes only for incompatible wire/layout changes.
  • Minor (ABI_VERSION_MINOR) changes for backward-compatible additions.
  • No silent renumbering of existing syscall IDs.
  • repr(C) and explicit size checks are mandatory for exported ABI structs.

Boot handoff ABI (strat9_abi::boot)

The bootloader/kernel handoff has its own version, STRAT9_BOOT_ABI_VERSION, independent from the syscall ABI_VERSION_* above. The kernel refuses to boot when it does not match exactly.

Boot handoff ABI — tracked separately

The boot struct is versioned on its own counter, not on ABI_VERSION_*.

VersionStructSizeNotes
2KernelArgs132 BSuperseded. Still described in workspace/bootloader/README.md
3KernelArgs132 BSuperseded
4 (STRAT9_BOOT_ABI_VERSION)KernelArgs132 BCurrent. Adds bss_virt_base / bss_virt_size, drops the stack_base / stack_size fields in favour of passing the stack in registers to paging::context_switch

STRAT9_BOOT_MAGIC = 0x5354_3942 ("ST9B"). The size is asserted at compile time in two places in workspace/abi/src/boot.rs.

Open inconsistency. strat9_abi::errno::ENOTSUP is 95, but the kernel's SyscallError::NotSupported in workspace/kernel/src/syscall/error.rs is still -52, so the kernel currently emits a value the ABI does not define. SyscallError also lacks ELOOP (40), EAFNOSUPPORT (97), EADDRINUSE (98) and ECONNREFUSED (111), which the ABI does define. See Syscall Reference → ENOTSUP numbering.
